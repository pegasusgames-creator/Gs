Run multiple timers simultaneously while you cook! Set timers for every dish and get loud alerts when each one is ready.

🍳 FEATURES
• Up to 8 simultaneous timers
• Name each timer (Pasta, Oven, Rice, etc.)
• Countdown display for each
• Loud alert when timer finishes
• Vibration alert option
• Preset timers for common foods
• Pause individual timers
• Works fully offline

🍽️ PRESETS INCLUDE
• Boiled eggs (soft/medium/hard)
• Pasta (spaghetti, penne, etc.)
• Rice and grains
• Roast chicken, steak temperatures
• Baking timers
