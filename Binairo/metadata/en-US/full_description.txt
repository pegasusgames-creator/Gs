Binairo (also called Binary Puzzle or Takuzu) is a pure logic puzzle — no guessing required!

🔢 HOW TO PLAY
Fill the grid with 0s and 1s following three simple rules:
• No three same values in a row or column
• Each row and column has equal 0s and 1s
• No two rows or columns are identical

🧩 FEATURES
• Multiple grid sizes: 6×6, 8×8, 10×10, 12×12
• 200+ handcrafted puzzles
• Auto-highlight rule violations
• Hint system for stuck moments
• Undo/redo buttons
• Clean, minimal interface
• Works fully offline
