FULL DESCRIPTION
========================================
The complete dice roller for tabletop RPGs, board games, and anything requiring a roll! All standard polyhedral dice plus custom options.

🎲 DICE AVAILABLE
• D4, D6, D8, D10, D12, D20 (standard RPG set)
• D2 (coin), D3, D100
• Custom: set any number of sides
• Roll multiple dice at once (e.g., 4d6 for character stats)

✨ FEATURES
• Roll multiple dice simultaneously
• Running total display
• Roll history log
• Shake phone to roll
• 3D dice animation
• Works fully offline

Perfect for D&D, Pathfinder, board games, and any game requiring dice. Download free!
