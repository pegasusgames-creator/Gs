========================================
FULL DESCRIPTION
========================================
A bright flashlight app with SOS signal mode! Use the screen as a powerful white light or activate SOS mode to flash the international distress signal.

🔦 FEATURES
• Full-screen white flashlight (maximum brightness)
• SOS mode: automatic 3-short, 3-long, 3-short morse code
• Strobe light with adjustable speed
• Screen stays on while in use
• Red night-vision mode
• Simple one-tap interface
• Works fully offline

✅ USES
• Emergencies and signaling for help
• Power outages
• Camping and outdoor activities
• Night reading
