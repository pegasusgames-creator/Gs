================================================================================
IMPLEMENTATION TEMPLATE
================================================================================
1. Copy BallSortPuzzle Android project folder
2. Change package name in:
   - AndroidManifest.xml
   - build.gradle (applicationId)
   - MainActivity.java (package declaration)
3. Register new app in:
   - Google Play Console (new app)
   - AdMob (new app → new ad unit IDs)
   - Firebase (new project → google-services.json)
4. Replace app/src/main/assets/game.html with new game
5. Update ADMOB_APP_ID + ad unit constants in MainActivity.java
6. Update product IDs in MainActivity.java + Play Console
7. Build release APK, sign, upload
